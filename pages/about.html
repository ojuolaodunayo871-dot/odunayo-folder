About System

This web application computerizes student attendance using secure, time-bond QR
codes for classroom session

Project Topic

Design and implementation of an Attendance Management System Using QR Codes

Roles
  • Admin - management users departments, courses, enrollments and system - wide report
  • Lecturer - create attendance sessions display QR codes monitor scans and export reports
  • Student - scan QR codes, view personal history and track attendance percentage
Technology

HTML5, CSS3, Boostrap 5, JavaScript, PHP8+,MySQL, html5-grcode, and QRCode.js
