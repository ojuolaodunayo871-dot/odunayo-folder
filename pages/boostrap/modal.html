ACADEMIC ATTENDANCE

QR Attend

Design and Implementation of an Attendance Management System
Using QR Code - scan once, record instantly.

How it works

Lecturers open a timed session students scan a secure QR token and attendance is stored with
course, lecturer, date, and time

Create Session

Lecturer start a class session with date, time,and duration. A unique token is generated for that session only.

Display QR Code

Project the QR code in class. It encodes a temporary session token- never a student ID

Scane & Confirm

Student scan with theirn phone camera. The system validates enrollment, session status and prevents duplication
